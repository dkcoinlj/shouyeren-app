通知测试与保活

提醒已改用 App 自身的系统通知直接下发（不依赖外部日历）。点下面按钮可当场验证；若仍收不到，多半是手机把本 App 的后台进程限制了。
收不到时这样处理：
① 系统设置里给「守夜人」开启「允许通知」与「锁屏显示」。
② 电池/省电里设为「不受限制」或加入自启动/白名单。
③ 部分国产手机（小米/华为/OPPO）需额外开启「允许后台弹出界面」。

国产安卓（OPPO/华为/小米）必做设置

ColorOS / EMUI / MIUI 对后台和通知管控极严，不设置会「杀后台、不弹通知、锁屏不显示」。装好后请逐项开启（以 OPPO ColorOS 为例，其他品牌路径相近）：
  1. 电池 → 应用耗电管理 → 守夜人：设为「允许后台运行 / 自启动 / 锁屏清理加入白名单」
  2. 设置 → 通知与状态栏 → 通知管理 → 守夜人：开启「允许通知」+「锁屏显示」+ 设为重要
  3. 设置 → 密码与安全 → 系统安全 → 未知来源应用：允许本次安装（仅首次装包用）
  4. 若仍不弹通知：设置 → 应用 → 守夜人 → 权限 → 精确闹钟 设为允许
